## Reproduzir verificações offline

Com Node da `.nvmrc` preparado, os exemplos abaixo usam `node` pelo PATH. Em P3.2, use a sessão do runtime independente verificado conforme [operações](OPERATIONS.md); a área portátil P0 antiga está ausente. As flags de symlinks usadas historicamente contornavam resolução de ancestrais e não são requisito da arquitetura. Para provar isolamento, repita os checks na instalação limpa, nunca substitua suas dependências pelas antigas.

Suíte permanente, sem Internet, DNS ou sockets reais:

```powershell
npm test
# Alternativa P3.2: distribuicao independente verificada, fora de node_modules.
$p32Runtime = Join-Path $env:TEMP 'CodeBucket-p32-runtime-20261123/node-v24.22.2-win-x64'
if (-not (Test-Path -LiteralPath "$p32Runtime/node.exe")) {
    throw 'Prepare o runtime oficial verificado conforme OPERATIONS antes de continuar.'
}
$env:PATH = "$p32Runtime;$env:PATH"
```

Contrato local, sem importar `index.js` ou `deploy-commands.js`, sem ler `.env` e sem chamar `execute`:

```powershell
@'
const fs = require('node:fs');
const path = require('node:path');
const names = new Set();
for (const file of fs.readdirSync('commands').filter(f => f.endsWith('.js'))) {
  const command = require(path.resolve('commands', file));
  if (typeof command.execute !== 'function' || typeof command.data?.toJSON !== 'function') {
    throw new Error(`Contrato invalido: ${file}`);
  }
  const data = command.data.toJSON();
  if (names.has(data.name)) throw new Error(`Nome duplicado: ${data.name}`);
  names.add(data.name);
}
console.log(`${names.size} comandos validos localmente`);
'@ | node --preserve-symlinks --preserve-symlinks-main -
if ($LASTEXITCODE -ne 0) { throw 'Falha no contrato dos comandos' }
```

## Pendências explícitas

`NOT_CONFIRMED`: auditoria de vulnerabilidades (`npm audit` desativado nas instalações anteriores), cobertura funcional integral de handlers/integrações, recuperação/reinicialização integral, registro remoto inspecionado e permissões detalhadas por contexto. Login e funcionamento agregado dos 23 comandos foram confirmados pelo responsável na P3.3, sem coleta individual ou logs. Essas verificações não foram marcadas como aprovadas. Instalações limpas P0/P1.1, cinco casos locais de `/formatar` em P0 e suítes offline P1.1/P1.2/P1.3/P2.1/P2.2 foram comprovados, sem equivaler a aprovação de operação remota.

Quando uma mudança de comportamento for autorizada, mantenha testes focados no risco alterado: erro após reply/defer, timer com limite/cancelamento/envio rejeitado, QR em Buffer sem escrita ou resposta de API inválida/excessiva. Não é necessário criar CI complexo para manter esta base documental.
